# ITNOA Marketing Website

This is your deployable Next.js website project.

## What I already did
- Built the React/Next.js homepage.
- Added Tailwind styling.
- Added Framer Motion animations.
- Added your ITNOA logo assets into `/public`.
- Added placeholders for videos:
  - `/public/hero-video.mp4`
  - `/public/showcase-video.mp4`

## What you need to do
1. Create a free GitHub account if you do not have one.
2. Create a free Vercel account.
3. Upload this project to GitHub.
4. Import the GitHub project into Vercel.
5. Connect your domain: `itnoamarketing.com`.
6. Replace video placeholders with your real videos.

## Run locally if you want
Install Node.js, then run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
